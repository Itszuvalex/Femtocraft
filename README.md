# Femtocraft
Femtocraft for Minecraft 26.1.2 / NeoForge, written in Kotlin on [ItszuLib](https://github.com/Itszuvalex/ItszuLib).

GitHub is the home of this repository; the full history from the former GitLab repo (https://gitlab.com/Itszuvalex-Minecraft/Femtocraft) is here.

- `main`: Minecraft 26.1.2 / NeoForge, written in Kotlin (the port of v3, merged from `neoforge-26.1`). Building needs an ItszuLib checkout next to this one (see `settings.gradle` and `AGENTS.md`).
- `develop`, `develop-1.12.2*` and the older `develop-*` branches: the Minecraft 1.12.2 (Forge, Scala) line and older versions.
